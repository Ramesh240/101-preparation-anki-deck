
# 101 Preparation — Full-Stack .NET + React + Azure Interview Prep (Anki Deck)

A mobile-optimized Anki flashcard deck for interview prep covering the
full .NET + React + Azure full-stack interview stack — built and refined
from real interview experience, then reformatted for clean, scrollable,
scannable review on your phone.

Each card follows a consistent structure: a short definition, a real code
example where relevant, and a one-line "Interview Answer" takeaway you can
actually say out loud.

## Features

- **Mobile-first card design** — centered question with a topic badge,
  fully scrollable answer (no more clipped/cut-off cards on phone screens)
- **Dark mode support** — follows your device's Anki night mode automatically
- **Clean code formatting** — code blocks wrap instead of forcing horizontal
  scrolling; comparison tables are responsive
- Organized into 13 topic-based subdecks so you can study by area or mix
  everything together

## Installation

1. Download `101_Preparation.apkg` from this repo 
or 
from AnkiWeb: https://ankiweb.net/shared/info/101042386
2. Open Anki (desktop, AnkiDroid, or AnkiMobile)
3. **File → Import** (or just open the `.apkg` file directly on mobile)
4. The 13 subdecks will be created automatically under `101 Preparation`
